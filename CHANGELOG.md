# Changelog

What's new in each release of Notes. The newest is at the top.

## 1.0.0

- Notes are plain Markdown (.md) files in a folder you choose; no account and no cloud.
- Notes and Folders tabs, search across titles and text, and sorting by last changed or title.
- Notes save themselves as you type, and update on screen when their file changes on another device or in another app.
- If a note changes elsewhere while you're editing it, you choose which version to keep.
- A formatted view with headings, lists, tickable checkboxes, quotes, code and links.
- New notes take their name from their first line if you don't give them a title.
- Undo after deleting a note.
